# 메인 아티클 카테고리 순환 — PR #93 추가 작업

메인은 방문·상담을 위한 랜딩페이지이므로 모든 글 대신 카테고리별 최신 글을 소개합니다. 변경은 PR #93의 기존 브랜치에 추가하며, 전체 목록의 필터·카테고리·태그 계약은 유지합니다.

## 빌드와 선정

- `scripts/categories.py`의 이름·ID·순서를 재사용합니다. 공개 글이 없는 카테고리는 메인 탭과 순환에서만 제외합니다. 새 공개 글이 생기면 다음 빌드에서 자동 포함됩니다.
- `home_article_groups()`는 공개 글을 발행일 내림차순, 같은 날짜에서는 URL 내림차순으로 정렬해 카테고리당 최대 4개를 선정합니다. 수정일은 순위에 사용하지 않습니다.
- 기존 HTML 글의 발행일은 보호된 원본의 `datePublished`를 읽습니다. 원본 HTML·해시를 수정하거나 발행일을 추정하지 않습니다.
- 빌더가 루트 `index.html`의 아티클 구간에 대응하는 출력만 `templates/home-articles.html`로 교체합니다. 원본 홈 HTML과 아티클 이외의 소개·상담·지도·방문 안내·푸터는 유지합니다.
- `templates/article-card.html`과 기존 Bootstrap `col-lg-6`, 간격·이미지·타이포그래피를 재사용합니다. PC는 최대 4개를 2열×2행, 기존 991.98px 이하에서는 앞의 최대 2개를 1열×2행으로 표시합니다. 글이 적으면 있는 글만 표시합니다.
- 최초 HTML에는 한 카테고리만 보이고 나머지는 `hidden`입니다. 전체 그룹도 카테고리당 4개, 최대 28개로 제한되므로 글이 늘어도 메인 길이는 늘어나지 않습니다.
- 항상 `/articles/index.html`로 연결하는 **전체 아티클 보기** CTA를 제공합니다. 전체 공개 글은 목록과 사이트맵에서 검색엔진이 발견할 수 있습니다.

## 클라이언트 동작

`js/home-articles.js`는 별도 라이브러리·API·카테고리 데이터 요청 없이 빌드된 그룹을 교체합니다. 전체 목록용 `js/article-filters.js`와 선택자·동작을 분리했습니다.

- 기본값은 정의 순서상 첫 번째 비어 있지 않은 카테고리입니다. 10초마다 다음 그룹으로 이동하고 마지막 다음에는 처음으로 돌아옵니다.
- 탭 클릭, 이전/다음 버튼, 터치·펜의 수평 스와이프로 즉시 전환합니다. 수동 조작 뒤에는 대기 시간을 다시 10초로 설정합니다.
- 탭은 `tablist`/`tab`/`tabpanel`, `aria-selected`, roving tabindex로 연결합니다. 좌우 화살표·Home/End로 탭을 선택하고, Tab 및 Enter/Space로 탭·전환 버튼·글 링크를 조작할 수 있습니다.
- 페이지 숨김·창 비활성, 영역 내 포커스, 마우스가 영역 위에 있는 동안, 터치·드래그 중, `prefers-reduced-motion: reduce`에서는 자동 전환을 중단합니다. 조건이 해제된 뒤 10초부터 다시 시작합니다. 정지·재생 버튼은 추가하지 않습니다.
- 탭을 클릭한 뒤에도 포커스가 영역에 남아 있다면 자동 전환은 계속 중단됩니다. 영역 밖으로 포커스/마우스를 옮기면 10초 후 재개됩니다.
- 스와이프는 이동 거리가 60px 이상이고 수평 이동이 수직 이동의 1.5배보다 클 때만 인정합니다. `touch-action: pan-y pinch-zoom`으로 세로 스크롤과 확대를 유지합니다. 스와이프 직후 생성되는 클릭만 막고 새 탭/클릭은 정상 처리합니다.
- 자동 전환은 포커스를 이동시키지 않습니다. 수동 스와이프로 포커스된 카드를 교체할 때만 새 탭에 `preventScroll`로 포커스를 옮깁니다. 상태 영역은 `aria-live="off"`로 반복 안내를 피합니다.
- 같은 뷰포트의 가장 높은 제한된 패널 높이를 예약해 카테고리 전환 시 CTA·지도 위치가 바뀌지 않도록 합니다. 선정된 이미지·폰트 로딩이 정착된 뒤 자동 타이머를 시작하고, 화면 너비 변경 시 높이를 다시 계산합니다. 카드 자체를 가로로 이동시키거나 페이지를 좌우로 움직이는 애니메이션은 없습니다.

## JavaScript 비활성·검수 시 주의

JavaScript 없이 기본 카테고리의 최대 4개(좁은 화면 2개) 링크와 전체 목록 CTA를 사용할 수 있습니다. 동작하지 않는 탭·화살표는 표시하지 않습니다. 전체 목록에는 여전히 7개 필터와 모든 공개 글이 있으며 자동 순환은 없습니다.

높이를 안정시키기 위해 글이 적거나 상대적으로 짧은 카테고리에서는 카드 아래 여백이 남을 수 있습니다. 예약 높이는 무제한 전체 글이 아니라 해당 화면에서 표시 가능한 최대 4개/2개 카드의 가장 높은 그룹을 기준으로 합니다. 동작 줄이기가 설정된 OS에서는 수동 전환으로 검수하세요.

여러 Markdown을 변경한 PR의 외부 프리뷰 한계는 그대로입니다. 프리뷰·러너 저장소는 수정하지 않습니다. 이 PR의 최신 `content-check` 실행이 제공하는 `site-review-<run_id>` 전체 사이트 아티팩트를 내려받아 로컬 HTTP 서버로 검수합니다. [기존 검수 안내](category-system.md#여러-markdown-변경-pr의-검수-대안)를 따르세요.
