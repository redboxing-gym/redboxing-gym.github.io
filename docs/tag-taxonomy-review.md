### 남는 한계와 별도 개선안

모든 변경이 일률적으로 개선된 것은 아니다. 뒤부아 글은 잽·콤비네이션을 둘 다 공유하는 호흡 입문 글이 경기 분석 하나만 공유하는 관전 글보다 앞선다. 글러브 글의 자동 추천 2개와 젖산 글의 마지막 추천은 공유 태그가 0개인 URL 순 보충이다. 스트레칭·발한·줄넘기·스파링 글은 초보자만 공유하는 후보가 반복된다. 일부 명시 입문 안내·발 교차 링크도 글의 세부 기술과는 거리가 있지만 원고 작성자가 지정한 우선순위라 유지했다. 본문에 없는 공통 태그를 넣어 이런 문제를 감추지 않았다.

향후 별도 제안(이번에는 미구현): 0개 일치 보충을 줄이거나 관련 글 개수를 줄이는 정책, 초보자 같은 독자 수준 태그의 점수 취급, 경기 종목·카테고리 동점 처리, 명시적 연결의 편집 검토를 실제 클릭·수동 평가와 함께 검토할 수 있다. 추천 알고리즘 변경은 별도 승인·PR 범위다.

## 향후 외부 사전 연동 참고

사이트는 구조가 올바른 문자열 목록을 읽고 출력·동일 문자열 비교를 수행한다. 고정 허용 목록, 사전 파일, 승인 절차, 개수 제한, 번역 ID를 추가하지 않았다. 1개·5개의 임의 한글 태그도 파싱할 수 있도록 회귀 검사한다. 기존 영어 문자열도 파서가 차단하지 않으며, 현재 원고 데이터의 한글 여부 검사는 사전 검증과 별개다.

향후 사전 관리 주체는 별도 러너다. 초기 권장 11개와 이 문서의 신규 제안을 외부에서 검토하고, 동의어의 최종 명칭·띄어쓰기·한글 NFC·본문 근거를 일관되게 적용하는 것이 좋다. 사이트는 앞뒤 공백·중복 표현을 자동 의미 통합하지 않으므로 생성 측에서 동일 관심사를 같은 문자열로 저장해야 관련 글이 연결된다. 태그 2~4개 권장은 문서 가이드이며 필수 제한으로 구현해서는 안 된다. kicker는 이번 변경 대상이 아니며 이전 한글 값을 그대로 유지했다.

이 문서의 기록은 향후 외부 사전 후보일 뿐 최종 정책이 아니다. 러너 저장소·프롬프트·스케줄·생성 로직·신규 태그 승인 시스템에는 접근하거나 수정하지 않았다. 러너가 기존 포괄 태그 또는 영어를 계속 생성하면 빌드는 구조상 읽을 수 있어도 현재 한글 데이터 검사나 추천 문자열 일치에 영향을 줄 수 있으므로 별도 작업에서 정합성을 맞춰야 한다.

## 검수와 프리뷰 호환성

기존 dist 출력 계약은 유지한다. 이 PR은 여러 Markdown을 수정하므로 기존 단일 Markdown 전용 프리뷰 시스템으로는 검수할 수 없다. 프리뷰 저장소를 수정하지 않고, PR의 `content-check`가 제공하는 전체 `site-review` 아티팩트를 내려받아 로컬 HTTP 서버로 열거나 사이트 저장소 브랜치에서 직접 `python scripts/build.py` 후 dist를 제공하는 방식으로 검수한다. 향후 여러 원고 변경·전체 사이트 아티팩트를 지원하는 프리뷰 개선은 별도 작업이다.
