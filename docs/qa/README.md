저장소 외부 임시 복사본의 테스트 원고만 `draft: false`로 바꾸고 빌드했습니다. 저장소 원고는 변경하지 않았으며 `draft: true`입니다. 로컬 HTTP 서버와 별도 headless Chromium 테스트 프로세스로 화면을 렌더링했습니다. 실제 GitHub Pages에 게시하지 않았습니다.

네 화면을 직접 확인했습니다. 제목·작성일·수정일·관련 글·전체 글 보기·아티클 보기 한글이 정상이며 기존 CSS의 대표 이미지, 문의 CTA, 반응형 본문·사이드바와 카드 구성이 적용됩니다. 모바일에서는 단일 열로 표시됩니다. 전체 페이지 스크린샷의 고정 문의 바는 캡처 시점 뷰포트 위치에 나타납니다.

브라우저 검사 결과는 [results.json](results.json)에 기록했습니다.

- 가로 넘침 없음: scrollWidth = viewport width (1440 / 390).
- 모든 이미지 정상 로드.
- 목록은 기존 5개와 임시 공개 글 1개, 총 카드 6개.
- 신규 글의 관련 글 3개와 전체 목록 링크 정상.
- 메인 `#articles`에 신규 카드 1개 추가 확인.
- 각 화면의 HTTP 400 이상 응답과 JavaScript 오류 없음.
- 루트 실제 빌드를 다시 확인: 초안 HTML 없음, 신규 공개 글 0개.

이 증거 파일은 docs 아래에 저장되므로 `dist/` 배포 결과에는 포함되지 않습니다. headless Chromium은 이번 화면 QA에만 사용하며 필수 빌드 의존성이나 유료 서비스가 아닙니다.
